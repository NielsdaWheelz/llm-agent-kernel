# installed callback containment and useful behavior

status: open; unimplemented experimental route, 2026-10-02.

problem: current provider denies dynamic callbacks and the kernel rejects native
tool events. documented dynamic tools do not prove contained callbacks with strict
output on the installed shared server. codapt's broad shell/http lane is different.

impact: a superficially successful probe could depend on undeclared shell/network,
lose research capability, or fail on disconnect/pending callbacks.

evidence: [review finding 8](../native-agent-review.md#8-callback-transport-is-proposed-while-many-reusable-tool-seams-already-exist)
and [official experimental surface](https://learn.chatgpt.com/docs/app-server#dynamic-tool-calls-experimental).
llm-tools/provider already supply publication, validation and execution seams;
do not duplicate them merely to create a native transport.

resolved when: exact installed build/pins prove several real callbacks, strict
final output, bounded serial dispatch, effective containment and real tool results.
qualify reply loss and fresh-thread canonical recovery; native callback reconnect
is deliberately excluded from the target. run the
small consumer quality/cost/control comparison before adoption. N009–N010, N012,
N014, N019–N020. nexus's existing-route research proof is separately N007.
all live cases are `NOT_RUN`; failure does not authorize shell/private-process fallback.
